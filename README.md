# My Tap-ON App

A mobile-first prototype for real-time community waste collection tracking, resident-to-collector communication, concern reporting, collection schedules, recycling-center information, and role-specific operating guides.

## Publish with GitHub Pages

1. Extract the ZIP file.
2. Upload **all extracted contents** to the root of the `rss-coder/my-tap-on-app` repository, including the `.github` folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **GitHub Actions** as the source.
5. Open the **Actions** tab and wait for “Deploy My Tap-ON to GitHub Pages” to finish.

The website should then be available at:

`https://rss-coder.github.io/my-tap-on-app/`

The website uses sample data for demonstration. A real deployment would require a secure backend, user authentication, GPS integration, and database connections.
